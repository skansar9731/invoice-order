🚀 Google Gemini 3.6 Flash & Netlify Deployment Guide
  1. Deploy this repository to Netlify (connected to GitHub or via Netlify CLI: netlify deploy --prod).
  2. In Netlify Dashboard, navigate to Site Configuration → Environment Variables.
  3. Add variable: GEMINI_API_KEY = Your Google Gemini API Key.
  4. The serverless function in netlify/functions/extract-order.js automatically calls Gemini 3.6 Flash and returns structured JSON: [{ customerText, quantity }].
  5. No API key is ever exposed in client-side code!
